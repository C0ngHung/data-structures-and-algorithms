# Project Brief — Data Structures and Algorithms

## Overview
A **learning-oriented Java project** for mastering Data Structures and Algorithms (DSA) concepts through hands-on implementation and bilingual documentation (Vietnamese + English).

## Core Goals
1. **Learn by Building** — Implement each data structure and algorithm from scratch in Java
2. **Deep Understanding** — Each implementation includes detailed bilingual comments explaining theory, complexity analysis, and real-world use cases
3. **Progressive Complexity** — Build from fundamentals (Big O, Arrays) to advanced topics (Trees, Sorting Algorithms)
4. **Interview Preparation** — Serve as a reference for technical interview prep

## Scope
| Area | Topics |
|------|--------|
| **Foundations** | Big O Notation (O(1), O(n), O(n²), O(log n), O(n log n), O(n³)) |
| **Data Structures** | Array (Dynamic Array), Linked List (Singly, Doubly), Stack, Queue, Hash Table, Binary Tree, BST |
| **Algorithms** | Bubble Sort, Merge Sort, Quick Sort, Binary Search, Recursion |

## Constraints
- Java 17 as the target JDK
- Spring Boot 4.0 project structure (Maven)
- Bilingual comments: Vietnamese (primary) + English
- Self-contained — no external data dependencies
